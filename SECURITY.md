# Security

Termight runs shell commands as you, so a bug that runs something you didn't
type, runs it differently, or leaks what you ran is a security problem.

## Reporting a problem

Please report it privately: on GitHub, open the **Security** tab of this
repository and choose **Report a vulnerability**. Don't open a public issue.

Include what you did, what happened, and the Termight version (Settings →
General → Updates shows it). A command or snippet that reproduces it helps
most.

You'll get a reply within a week. Fixes go out in a new release, and the
in-app updater offers it to everyone.

## Supported versions

Only the latest release gets fixes.
